🧪 Birthdate Change Test

Experiment lang ito — titignan natin kung gumagana pa yung users.roblox.com/v1/birthdate endpoint. Hindi nasesave ang password mo anywhere. 


    


    

      Mga karaniwang response:

      • 200 / empty = gumana, nabago na yung birthday

      • 403 + InvalidPassword = mali yung password na inilagay

      • 403 + InvalidBirthdate = hindi valid yung date (e.g. age < 13 hanggang 2024 policy, o sobrang bata/tanda)

      • 403 + VerificationRequired / age-related error = naka-lock na yung DOB, kailangan dumaan sa official Settings flow

      • 429 / Flooded = masyadong maraming attempt, hintayan muna
